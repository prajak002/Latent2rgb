A diagnostic protocol for latent-only world models

Horizon Ladder

Research gap

Rolling a frozen state predictor forward produces a latent for a future that never happened, so there's no real image to check it against. Nobody has separated how wrong the dynamics are from how wrong the decoder is along that horizon, nobody has checked whether a decoder stays faithful to counterfactual action differences, and nobody has measured how a single decode error compounds when it's re-injected into the rollout. This run targets the first of those three.

What this is doing

A frozen V-JEPA2 ViT-L encoder and predictor — genuinely latent-only, no built-in pixel decoder — is queried on real Something-Something v2 clips: given only frames up to time t, predict the tubelet at t+k, for k = 2, 4, 8, 16, 32 frames out. A small, deliberately low-capacity decoder (trained only on real frames, never on rollouts) turns each predicted latent back into pixels, so it can be compared against the real future frame directly.

Caveat that shapes every number below: this predictor was pretrained to fill in masked patches of an already-fully-observed clip, never to predict a genuinely unseen future from a causal past. Querying it that way is possible but untested by its own authors — so this measures the frozen model under an out-of-distribution query, not a clean read of its forward dynamics.
